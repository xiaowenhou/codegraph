4. 本次定制了哪些功能

目标：让 PEMS（Spring Boot 项目）的 @Scheduled/@PostConstruct/@PreDestroy/@Async 注解方法在图谱中不再断链（原 callers 为空）。

注解图谱建模效果（PEMS 实测）
@Scheduled 提取阶段创建 route 入口 SCHEDULED cron="…" callers scheduleSync → route SCHEDULED fixedRateString="${mqtt.sync.interval:300000}"（原为空）
@PostConstruct 合成「宿主类 → 方法」calls 边（bean 生命周期增强） callers TaskScheduler.start → class TaskScheduler
@PreDestroy 同上 callers TaskScheduler.stop → class TaskScheduler
@Async（无静态调用方） 合成「宿主类 → 方法」calls 边（异步入口） callers onThresholdAlarm → method handle(事件边) + class AlarmLogEngine(@Async 入口) 并存
@Async（有静态调用方） 不建边 保持原有真实调用边，不产生额外入口（条件逻辑）

附带增强

  • 框架探测增强：springResolver.detect() 补认 @Controller/@Component/@Configuration/@Bean（原只认 @SpringBootApplication/@RestController/@Service/@Repository）——纯 @Component 项目也能启用 Spring 框架解析。
  • 默认可见性方法：无 public/private/protected 修饰符的 @Scheduled 方法也能建入口（Spring 通过反射调度非 public 方法）。
  • 跨行注解：注解块扫描支持多行参数（@Anno(\n value=x\n)）与空行，不再漏检。
  • route id 消歧：同一方法叠多个 @Scheduled 时 id/qualifiedName 可区分。
  • 宿主类解析加固：按 kind 过滤 contains parent，只认 class/interface/struct。
